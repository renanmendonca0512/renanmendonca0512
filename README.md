## Olá, eu sou o Renan 👋

Desenvolvo ferramentas de **automação comercial**: levar leads até o CRM sem trabalho manual,
triar candidatos com ajuda de IA e dar à equipe de vendas dados confiáveis para agir rápido.

### O que eu construo

- **Envio de leads para qualquer CRM** — importa planilhas JSON/CSV e envia para qualquer API
  (CRMs, webhooks, Zapier/Make/n8n), em paralelo, com tokens cifrados e histórico de cada envio.
  1.400 leads em menos de 1 minuto.
- **Triagem de candidatos com IA** — lê currículos, anonimiza os dados pessoais, avalia contra
  uma régua por vaga e entrega um ranking com justificativas. A decisão final é sempre humana (LGPD).
- **API de CRM multiempresa** — base de um CRM com funil, leads e isolamento entre empresas.

### Ferramentas

`JavaScript` · `Node.js` · `Express` · `TypeScript` · `Python` · `FastAPI` · `SQLite` · `PostgreSQL` · `Prisma` · `IA (Claude, Gemini)`

### Como trabalho

- Segurança desde o início: segredos fora do código, dados pessoais protegidos.
- Testes automatizados no que importa.
- Interface simples para quem não é técnico.
